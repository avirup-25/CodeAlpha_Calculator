 Professional Calculator Web App

A clean, responsive calculator built using HTML, CSS, and JavaScript.

## 🔧 Features
- Basic operations: +, −, ×, ÷
- Clear (C) and Delete (DEL)
- Real-time display
- Responsive UI (works on mobile & desktop)

## 🛠 Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
